# Сайт Риммы Салимовой

Статический сайт: главная, 3 страницы услуг, блог с 8 статьями. Сборка и установка зависимостей для публикации не нужны.

## Размещение
Для существующего Vercel-проекта: подключите этот репозиторий, выберите Other, корневая папка — корень репозитория, без команды сборки. Адрес для canonical и sitemap настроен на https://rimma-sites.vercel.app. При смене домена замените его во всех HTML, robots.txt и sitemap.xml.

## Содержание
По данным владельца: проекты от 10 000 ₽, ориентир 5–7 рабочих дней. Итоговые условия согласуются под задачу. В качестве примера работы описан сам сайт; клиентское портфолио нужно добавить после получения реальных работ. Контакты сохранены из предоставленного исходника; проверьте, что Instagram принадлежит Римме.

После запуска проверьте страницы, robots.txt и sitemap.xml на опубликованном домене. Отправка sitemap в панели поисковых систем требует доступа к подтверждённому сайту.
